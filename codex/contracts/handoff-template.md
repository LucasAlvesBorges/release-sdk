# Handoff template

Use only when work continues in another thread/session — not for a normal
task-complete summary. Limit: 60 lines or ~500 tokens (matches
`handoff-writer`'s output budget).

```md
# Handoff: <task>

## Objective
One sentence.

## Current state
Up to five items.

## Decisions
Only decisions that constrain the next step.

## Relevant files
Short list with the reason each matters.

## Tests
Command and result.

## Open items
Objective, unresolved points.

## Next action
One clear action.
```
